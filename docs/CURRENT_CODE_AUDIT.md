# تدقيق النسخة الحالية — 2026-11-22
المصدر المفحوص: development/index.html من مستودع abuali (وليس ضماناً أنه مطابق لنشر Vercel).

## نتائج مؤكدة من الكود
- توجد عناصر واجهة: conversationAudioCall وconversationVideoCall، وكذلك requestAudioCall وrequestVideoCall في سجل المكالمات.
- توجد دالة requestConversationCall تستدعي RPC باسم create_chat_call، وتعرض حالة الطلب.
- توجد آلية WebRTC أولية: send_chat_call_signal وchat_call_signals، مع تحكم بوسائط الاتصال.
- توجد إعدادات ملف شخصي وصورة شخصية، وحظر مستخدم، وتفضيلات خصوصية بعضها مذكور في الواجهة بأنه مجرد تفضيل.
- لا يمكن الاستنتاج من وجود عناصر HTML أن أزرار المكالمات مرئية أو أن RPC موجودة أو أن الاتصال يعمل في الإنتاج.

## سبب محتمل لعدم ظهور الأزرار
اختلاف نسخة development عن الإصدار المنشور، أو شرط إظهار رأس المحادثة، أو CSS يخفي العناصر. يلزم مقارنة نشر Vercel بالملف وفحص عناصر DOM عند اختيار محادثة. لا يجوز إعلان السبب نهائياً قبل ذلك.

## بوابات العمل
1. تحديد قاعدة البيانات الفعلية، جداول profiles/conversations/messages وRPC وRLS القائمة.
2. اختبار عنصرَي الاتصال في DOM مع حسابين، وفحص console وNetwork ووجود RPC.
3. تطبيق قاعدة الصداقة على الخادم ثم الواجهة، مع الحفاظ على محادثات المستخدمين القديمة.
4. تشغيل اختبار طرفين على بيئة تجريبية قبل النشر.

## حماية النسخة
لا تغيير للإنتاج، لا ترحيل هدّام، ولا ادعاء تشغيل مكالمات دون اختبار.
